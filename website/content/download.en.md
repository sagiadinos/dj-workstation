builds:
  - system: Linux
    arch: x86 64-bit
    file: latest_linux_x64.AppImage
    hint: Make the file executable and start it.
  - system: Linux ARM
    arch: ARM 64-bit, Raspberry Pi 4 and 5
    file: latest_linux_aarch64.AppImage
    hint: Make the file executable and start it.
  - system: Windows
    arch: x86 64-bit, Windows 10 and 11
    file: latest_windows_x64.zip
    hint: Unpack the archive and start djw.exe. No installation needed. If Windows SmartScreen warns, choose “More info” and “Run anyway”.
  - system: macOS
    arch: Apple silicon
    file: latest_macos_arm64.dmg
    hint: Open the disk image and drag the app into Applications. If macOS blocks the app, allow it under System Settings → Privacy & Security.
